Build distinctive, production-grade frontend interfaces that avoid generic AI
aesthetics. Implement real working code with deliberate visual direction and
refined execution.

The user provides frontend requirements (component, page, app, or interface),
plus optional context like audience, brand, stack, and constraints.

## Design Thinking

Before coding, set a clear aesthetic direction:

- Purpose: Define user, job-to-be-done, and success criteria.
- Tone: Pick a strong style direction (minimal, editorial, brutalist,
  playful, luxury, retro-futuristic, etc.) and commit.
- Constraints: Respect framework, accessibility, performance, and platform
  limits.
- Differentiation: Define one memorable visual idea to anchor the design.

Execute with intentionality. Bold and minimal both work; inconsistency does
not.

Then implement working code (HTML/CSS/JS, React, Vue, etc.) that is:

- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear point of view
- Refined in details (spacing, hierarchy, states, motion)

## Aesthetic Guidelines

Prioritize:

- Typography: Use expressive, context-fit type pairings; avoid default-looking
  stacks.
- Color and theme: Commit to a coherent palette; use CSS variables/tokens.
- Motion: Add meaningful animation moments (load, reveal, hover, scroll);
  avoid random micro-motion noise.
- Spatial composition: Use strong layout decisions (asymmetry, contrast,
  rhythm, negative space) where appropriate.
- Background and detail: Build atmosphere with textures, gradients, patterns,
  overlays, borders, shadows, or other contextual effects.

Avoid repetitive AI patterns: generic font defaults, predictable component
layouts, and overused palette cliches.

Match implementation complexity to design intent. Maximalist concepts need
richer systems; minimalist concepts need precision and restraint.
