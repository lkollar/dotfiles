## LLM Wiki

- Read `index.md` before operating; search existing notes before creating pages.
- `Sources/` contains immutable external evidence, mirrored by domain.
- `Wiki/` contains generated synthesis, mirrored by domain.
- Existing domain folders contain human notes; preserve their prose.
- `Hubs/`, `Templates/`, `index.md`, `CONTEXT.md`, and `docs/` are vault support.
- Paths define editing ownership. Use `type` and concise `tags`; do not add
  `owner` or `status`.
- Use relative Obsidian-compatible Markdown links and update them after moves.
- Maintain `Wiki/index.md` and append material changes to `Wiki/log.md`.
- Use `$llm-wiki` for setup, migration, ingest, query, and lint workflows.
