---
name: grill-with-docs
description: A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.
---

Run a focused, one-question-at-a-time interview in this skill. Use
`$domain-modeling` when terminology or decisions need recording.

1. Inspect repository instructions and existing context, glossary, and ADRs.
2. Establish the outcome, output, scope, exclusions, authority, done condition,
   and first proof.
3. Ask one question at a time. Recommend a default when useful.
4. Record settled terms and decisions in the existing glossary, context, or ADR
   location. Create the smallest missing document when appropriate.
5. Do not implement code or publish issues unless separately requested.
6. Finish with decisions, unresolved questions, changed docs, and next action.
