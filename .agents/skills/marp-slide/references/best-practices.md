# Marp Slide Best Practices

- One slide, one message.
- Use 3-5 bullets per slide.
- Keep titles concise.
- Keep body text short.
- Use consistent grammar in lists.
- Prefer whitespace over dense text.
- Use images to clarify, not decorate.
- Use title, agenda, content, summary flow.
- Use embedded CSS for portable decks.

Typical slide counts:

- 5 minutes: 5-8 slides
- 10 minutes: 10-15 slides
- 20 minutes: 15-25 slides

Checklist:

- Theme matches content.
- Title slide uses `<!-- _class: lead -->`.
- CSS is embedded.
- Images use Marp syntax.
- Text is readable.
- Deck has clear flow.
