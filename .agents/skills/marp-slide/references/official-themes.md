# Official Marp Themes

Marp includes:

- `default`: simple, versatile.
- `gaia`: colorful, energetic.
- `uncover`: minimal, elegant.

Use:

```markdown
---
marp: true
theme: default
---
```

Common classes:

```markdown
<!-- _class: lead -->
<!-- _class: invert -->
<!-- _class: lead invert -->
```

Official implementation:

https://github.com/marp-team/marp-core/tree/main/themes
