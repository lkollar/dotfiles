# Marp Image Patterns

Regular image:

```markdown
![alt](image.png)
![w:600px](image.png)
![h:400px](image.png)
```

Background image:

```markdown
![bg](image.png)
![bg cover](image.png)
![bg contain](image.png)
![bg brightness:0.5](image.png)
```

Split layouts:

```markdown
![bg right:40%](image.png)
![bg left:33%](image.png)
![bg vertical](top.png)
![bg](bottom.png)
```

Filters:

- `brightness:0.5`
- `contrast:1.2`
- `blur:5px`
- `grayscale`
- `opacity:0.5`

Use image paths relative to the Markdown file.

Official docs: https://marpit.marp.app/image-syntax
